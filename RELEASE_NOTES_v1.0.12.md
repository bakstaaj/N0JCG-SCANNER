# PI Scanner v1.0.12

- Restores the complete counters/status row above the analog control bar.
- Keeps the analog controls in a separate full-width row below the counters.
- Enables Squelch −/+ while analog workers are scanning or receiving.
- Disables Squelch only while P25 owns the audio.
- Applies scanning-time squelch changes to both VHF and UHF bands.
- Keeps Skip and Block enabled only for identified active analog traffic.
- Enables Clear All Blocks only when at least one active skip or block exists.
