# PI Scanner v1.0.14

- Places Skip, Block, and Clear All Blocks on one full-width row.
- Places Squelch −, the live absolute threshold, and Squelch + on the row above.
- Shows the active band threshold while receiving analog traffic.
- Shows one shared value while scanning when VHF and UHF match.
- Shows separate VHF and UHF values when their thresholds differ.
