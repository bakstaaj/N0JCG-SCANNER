# PI-P25-SCANNER v0.5.0

Release date: 2026-07-11

## Summary

This release packages the current working Raspberry Pi P25 scanner state after the RadioReference import, browser-audio, RTL serial isolation, and startup-service work.

## Major changes

- RadioReference workflow improvements:
  - Official RadioReference SOAP2 login/status flow.
  - System and site discovery for Arizona/Maricopa/Mesa.
  - Verified TOPAZ Regional Wireless Cooperative / TRWC discovery path.
  - Explicit site-frequency import handling for control and site frequencies.
  - Talkgroup category filtering during import.
- Browser audio and scanner startup:
  - Restored working web-page scanner/audio startup behavior after desktop-launcher rollback.
  - Preserved manual Start Scanner + Audio control.
- RTL-SDR isolation:
  - P25 scanner constrained to RTL serials in the 0000025X pool.
  - Current roles:
    - p25_control: 00000251
    - p25_voice: 00000252
  - OP25 validated marker uses rtl=00000251.
  - ADS-B radios are kept out of the P25 scanner role pool.
- OP25/runtime behavior:
  - Preserves known-good TOPAZ/TRWC Mesa control-channel and talkgroup baseline.
  - Keeps encrypted talkgroups blocked/muted/skipped rather than decoded.
  - Preserves browser-host audio architecture.
- Audio volume startup support:
  - Adds startup support for setting ALSA mixer controls before backend startup when the audio-volume service patch is present:
    - Speaker 100%
    - Speaker AC 100%
    - Speaker DC 100%
    - alsactl store

## Validation targets

- Backend: http://192.168.254.63:8070/api/status
- OP25 launch marker: runtime/settings/op25_validated_rx_command.env
- P25 RTL pool: 00000251 and 00000252
- Browser audio bridge: UDP PCM path to browser host audio

## Notes

The release intentionally keeps runtime/generated data under ignored runtime paths. Named configs remain local runtime data and are not committed unless explicitly copied into source-controlled config templates.
